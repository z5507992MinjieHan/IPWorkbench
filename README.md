# IPWorkbench · 新媒体 IP 工作台

一个本地运行的新媒体内容工作台：把对标账号采集、素材沉淀、AI 成稿、终稿归档和提词拍摄串成一条线，全部数据存在你自己的电脑上。

当前版本 v1.1.0（2026-11-17）

## 能做什么
- 对标库：粘贴抖音或小红书主页链接，自动采集账号资料与作品，生成账号观察
- 素材库：单条作品采集、分享文案解析、图片转文字、标签与评级
- 文案工坊：从素材生成初稿，也可以从零自主创作；三个字段可单独让 AI 按指令改写
- 我的风格模型：用自己的终稿训练写作风格，生成时调用
- 四项自检：选题、钩子、信息密度、行动项打分，附原句依据
- 终稿库与提词器：终稿归档后直接提词，支持手机扫码在同一局域网内提词
- 界面支持中文/英文、深浅主题、六种强调色
